ARCHITECTURE IMPROVEMENTS
================================================================================
BEFORE (Monolithic):
  Game ──┐
         ├──> Direct JDBC to H2 database (scope conflict!)
  DB Service ── same H2 database (file-locking issues)
  Web ─────┘
AFTER (Three-Layer):
  Game ──> REST ──> Web Gateway ──> Database Service ──> H2 Database
Benefits:
  ✅ No file-locking conflicts (game doesn't touch database file)
  ✅ Independent deployments (each service can be updated separately)
  ✅ Network isolation (game can run on different machine)
  ✅ Scalability (database layer can be clustered)
  ✅ Clean separation of concerns (each layer has one responsibility)
